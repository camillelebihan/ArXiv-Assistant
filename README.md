# arXiv Digest Bot

A Telegram bot that posts a daily digest of new arXiv papers on **finance and foundation models**, each with a 3-line summary generated by Gemini.

- Sources: `q-fin.*` categories (all papers) and `cs.LG` (only papers matching finance / foundation-model keywords)
- Summaries: Gemini, with a fallback to the abstract's first sentences if the API fails
- No duplicates: papers already sent are stored in SQLite
- Runs in Docker, every day at 08:00 Paris time

## Setup

1. **Telegram bot:** message [@BotFather](https://t.me/BotFather), run `/newbot`, copy the token.
2. **Chat ID:** send any message to your bot, then open `https://api.telegram.org/bot<TOKEN>/getUpdates` and copy `chat.id`.
3. **Gemini key:** create one at [Google AI Studio](https://aistudio.google.com/apikey).
4. Configure:
   ```bash
   cp .env.example .env   # then fill in the three required values
   ```

## Run

```bash
docker compose up -d --build                       # daily schedule
docker compose run --rm bot python -m src.main --once   # send one digest now
```

## Code review

Pull requests are reviewed automatically by [Gemini Code Assist](https://github.com/apps/gemini-code-assist). Review settings live in `.gemini/config.yaml` and `.gemini/styleguide.md`. CI runs lint, tests and a Docker build on every PR.

## Project structure

```
src/
├── arxiv_client.py   # fetch + filter papers
├── summarizer.py     # Gemini summaries
├── telegram.py       # formatting + sending
├── storage.py        # SQLite "already sent" store
├── config.py         # environment settings
└── main.py           # scheduler / entry point
```
